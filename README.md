# 🏨 Sistema de Reservas de Habitaciones de Hotel

Sistema de reservas para hoteles en Java, que permite gestionar habitaciones con tipos y precios distintos, reservar y liberar habitaciones, y manejar errores de manera personalizada.

## 🚀 Funcionalidades

- **Ver Detalles de Habitaciones**: Muestra tipo, precio por noche y disponibilidad.
- **Reservar Habitación**: Permite al usuario seleccionar y reservar una habitación para un número específico de noches.
- **Liberar Habitación**: Marca la habitación como disponible nuevamente.

## ⚠️ Excepciones Personalizadas

- `HabitacionNoDisponibleException`: Si se intenta reservar una habitación ocupada.
- `NumeroDeNochesInvalidoException`: Si el número de noches ingresado es menor a 1.
